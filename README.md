# Advanced Resource & Shift Planner (Community)

This module provides advanced shift and resource planning features for Odoo 19 Community Edition. It emulates enterprise-level planning functionalities using standard community components.

## Features

- **Shift Planning**: Create and assign shifts to employees.
- **Views**: Support for List, Form, Calendar, Gantt, Pivot, and Graph views.
- **Conflict Detection**: Automatically detects overlapping shifts and warns if an employee exceeds their maximum weekly hours.
- **Leave Integration**: Checks employee leaves and prevents shift assignment during absences.
- **Multi-Company**: Fully supports multi-company and proper access rules.

## Installation

1. Copy the `shift_planner_community` folder to your Odoo custom addons directory.
2. Update the app list in your Odoo instance.
3. Search for "Advanced Resource & Shift Planner" and click "Install".

## Usage

1. Go to the new **Planning** app in the main menu.
2. Under **Schedule -> Shifts**, you can create and manage shifts.
3. Configure the maximum weekly hours for employees in their profile under the **HR Settings** tab.
